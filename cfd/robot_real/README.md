# BODY2 真实几何（来自 身体总装.STEP）

- 单位：米。坐标系：OpenFOAM 约定 —— x 前进方向（+x 是艏），y 横向（左 = +y），z 向上。
  由 SolidWorks 坐标 (X, Y, Z) 变换：foam = (−X, Z, Y)，依据 架子_左前/右前 在 −X 侧、Y 向上、左 = +Z。
- hull.stl      湿表面集合 + 盖板：密封身体、4 扇形足、会碰水的连杆（17 个零件），封闭、法向一致，43 956 三角形。算例用这个。
- hull_all.stl  全部 37 个零件 + 盖板（含水面以上的舵机/架子），仅供查看；零件之间有贴合面，不建议直接划网格。
- parts/        每个零件实例一个 STL（index.json 给出零件名 ↔ 文件名），以后做运动部件时按这个拆。
- 密封身体在 STEP 里是开口托盘（无盖），已在顶部补一块盖板（parts/lid_1.stl），否则内腔会被划网格。
- 四条腿处于不同相位，左右不对称 → 必须用全模型（setup_robot.sh 的 FULL=1），阻力不再 ×2。
