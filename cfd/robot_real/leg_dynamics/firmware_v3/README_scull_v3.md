# 摇橹式尾鳍：新固件的 7 个控制点

固件：`gait_task.c`（新腿型：O1 = (−21.8, 22)，O1A 30，AC 35，O2C 30，O2E 30，EM 45；足端 M 原点 O2，+x 前进，+y 上）。
逆解用 `Leg_Solve2DIK_v3` 的逐行移植（`leg_v3.py`）复核过：注释里 IK_Path 那组原始点算出的 q1 ∈ [13.8, 86.7]、γ ∈ [−99.7, −17.3]、∠ACO2 ∈ [44.1, 109.1]、∠O2EM ∈ [82.5, 122] 与文件头一字不差。

## 运动
- 大腿不动：γ = −85°（近竖直，E ≈ (2.6, −29.9)）。
- 杆（小腿 = 尾鳍脚）绕 E 正弦摆：q_r = 40° ± 25°，即杆朝船尾方向下倾 15° … 65°。
- 7 点 = 同一段圆弧上下往返的折线（弦长误差 < 0.5 mm）；cp3 = cp4 让"锁 q1"段退化成 3 % 的换向停顿。
- 尾鳍枢轴横向扫 ±20 mm（枢轴离 E 47 mm）/ ±26 mm（62 mm）。冲程顶端枢轴 y = −42（O2 系），尾鳍内侧尖离船底 8 mm；底端 −72。
- 推力沿杆指向髋部：**前进 77 %、向上 64 %**（杆平均下倾 40°）。四桨向上分量约 5 g，可忽略。前进/后退方向由脚朝向决定，不由轨迹决定。

## 往 Watch / 源码里填的值
```c
/* 大腿定住、杆正弦摆的 7 点（q_r 15…65°, γ −85°） */
swim_cp0_xM = -40.9f;  swim_cp0_yM = -41.5f;   /* 顶端  q_r 15  */
swim_cp1_xM = -37.3f;  swim_cp1_yM = -50.7f;   /*       q_r 27.5*/
swim_cp2_xM = -24.8f;  swim_cp2_yM = -65.6f;   /*       q_r 52.5*/
swim_cp3_xM = -16.4f;  swim_cp3_yM = -70.7f;   /* 底端  q_r 65  → 锁 q1 */
swim_cp4_xM = -16.4f;  swim_cp4_yM = -70.7f;   /* = cp3，锁定段变成 3 % 停顿 */
swim_cp5_xM = -24.8f;  swim_cp5_yM = -65.6f;
swim_cp6_xM = -37.3f;  swim_cp6_yM = -50.7f;

swim_cp1_phase = 0.167f;  swim_cp2_phase = 0.333f;  swim_cp3_phase = 0.500f;
swim_cp4_phase = 0.530f;  swim_cp5_phase = 0.687f;  swim_cp6_phase = 0.843f;
/* cp1_phase 每帧会被 swim_rc_power_ratio 覆盖，所以这两个也要改： */
swim_rc_power_ratio_min = 0.167f;  swim_rc_power_ratio_max = 0.167f;

swim_seg_shape[] = { 0, 0, 0, 3, 0, 0, 0 };   /* 全部直线（段 3 是锁定弧，改不了，反正长度为 0） */
swim_smooth_enable = 0.0f;                    /* 段内匀速；开着的话脚会在每个控制点停一下 */
swim_freq_hz：1.0 起步，最高 1.5（CH5）
```

## 观察要点
1. 架空：两条前腿大腿不动，小腿（尾鳍脚）前后摆 50°，脚尖走弧线。
2. 下水：尾鳍应在每个半冲程自己"转橹"（相对杆 ±25–30°）。不转 = 叶簧太硬，削窄；转到顶 T 臂 = 太软。
3. 船动起来后再加频率。
