# 摇橹式尾鳍游泳：电控轨迹

固件（`gait_task.c`，MODE 5）的流程：足端 J 轨迹 (yJ, zJ) → `Leg_Solve2DIK_v2` 解 q1、q2 → `theta = offset + sign·q` → PWM。游泳用 `swim_leg_pose()`（4 个控制点分段插值）。**新脚只需要换 J 的轨迹，IK、映射、相位都不用动。**

固件几何（`Leg_GeometryV2`）：AB 30、BC 35、CE 52、EH 16.2、HI 52、IJ 51、AH 50。A = 髋轴（q2 舵机），脚 I–J 与 A–H 同向，所以 **q2 就是杆（尾鳍中立方向）的角度**；长杆 E–H–I 的角度由曲柄 q1 经拉杆决定。

## 目标运动（2026-09-18 改：整体下移 18°，避免尾鳍顶到船底）
长杆保持竖直，杆绕 A 正弦摆 **−18° ± 18°**（冲程顶端杆水平，底端向下 36°）：
J(φ) = ( 101·cos θ, −52 + 101·sin θ )，θ = −18° + 18°·sin(2πφ)
→ 圆心 (0, −52)、半径 101 的圆弧，尾鳍铰轴（≈ J）沉浮 ±31 mm，顶端 z = −52（船底在髋轴下 39 → 离船底 13 mm），底端 −111。
原来的对称摆动（0° ± 18°）顶端到 z = −21，尾鳍内侧会进入船底（见 `parts/fig_size_check.png`）。

| | 数值 |
|---|---|
| q2 | −36 … 0°（= 杆角） |
| q1 | 13.9 … 55.1°（IK 得出） |
| 峰值角速度 1.5 Hz | q1 194 °/s，q2 170 °/s（2 Hz：259 / 227；舵机 820） |
| J 范围 | y 82 … 101，z −111 … −52 |
| 各腿舵机角（现有 offset/sign） | LF θ1 90–131 θ2 53–89；RF 46–87 / 106–142；LH 65–106 / 48–84；RH 73–114 / 98–134 —— 都在 0–180 内 |
| 相位 | 沿用 swim_phase_off：LF 0, RF 0.5, LH 0.5, RH 0（对角同相） |
| 频率 | 1.5 Hz（CH5 可调 0.5–2） |
| 船的前进方向 | 尾鳍拖行的反方向：脚朝 +y（前）时船向 −y 游 |
| 压载 / 水深 | 水面到船顶（+11 mm）；尾鳍底端在水线下 ≈ 120 mm → 水深 ≥ 15 cm |

## 两种接入方式
1. **代码补丁（推荐）**：`scull_gait_patch.c` —— 一个 `scull_leg_pose()`（正弦圆弧，10 行），在 `walk_trot_select == 2` 分支把 4 个 `swim_leg_pose` 换成它。幅度 `scull_theta0_deg`（18° 起步，最大 22°）和平均角 `scull_theta_mean_deg`（−18°；改 0 回到对称摆动）都可在 Watch 里改。
2. **不改代码，只改控制点**（用弦线代替圆弧，长杆最多偏 6°）：
   `swim_cp0 = (101, −52)`，`swim_cp1 = (82, −111)`，`swim_cp2 = swim_cp3 = (101, −52)`，`swim_cp1_phase = 0.5`，`swim_cp2_phase = 0.98`，`swim_cp3_phase = 0.99`，`swim_smooth_enable = 1`。
   注意 CH6 会改 `swim_cp1_phase`（原来是划水占比）——用这种方式时把 CH6 放中位或把 1357 行注释掉。

## 文件
- `scull_traj_100ppc.csv`：一个周期 100 点：phase, t, yJ, zJ, 杆角, q1, q2, E/I 坐标, 四条腿 theta1/theta2（用固件同款 IK 算的，FK 复核误差 0）
- `scull_gait_patch.c`：补丁代码
- `scull_trajectory.py`：生成脚本（改 `TH0_DEG`、`F_HZ` 重跑；IK 是 `Leg_Solve2DIK_v2` 的逐行移植）
- `fig_scull_traj.png`：腿平面轨迹 + 关节角曲线

## 验证顺序
1. 架空，MODE 5 选 Swim，看四条腿：杆从水平往下摆到 −36° 再回来，长杆始终竖直，脚尖走圆弧。
2. 装尾鳍脚，水槽系留：尾鳍应在每个半周期自己"转橹"（相对杆 ±25–30°），不转说明叶簧太硬（削窄）。
3. 测推力，再调频率 / 幅度。
