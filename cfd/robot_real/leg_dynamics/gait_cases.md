# 单腿准定常叶素模型 —— 步态/脚蹼参数对比（单腿周期平均 x 向力，mN，+ = 推力）

模型：leg_dynamics.py（第 0 级运动学 + 第 1 级准定常叶素），几何来自 STEP 销孔重建（FL 腿）。
运动学约束（v2 修正）：平行四边形用相对角 φ = θ2 − ψ 描述，φ ∈ (0°,180°) —— 始终在摇臂左侧，不越过；
    φ≈105° 伸展（CAD 位姿 109°），φ→小 = 蜷缩（桨板折起贴向摇臂，姿态不变）。整套机构在 x–z 平面内运动。
"drag" = 压差项（标准阻力式划水推力估计）；"addm" = 附加质量项（周期均值取决于松线时机，需 CFD 校核）。
基准步态由视频估计：T = 1.25 s，髋摆幅 60°；脚蹼：收拢 = CAD 桨头 30 mm，展开 = 扇形 r = 42 mm。

关键结论（定性排序可靠，绝对数值 ±50%）：
1. 对称步态（划水/回收各半、划水结束才松线）净推力 ≈ 0：脚蹼 1.5 倍面积变化不足以制造推力，推进必须靠"不对称"。
2. 松线时机是最大的单一杠杆：在桨达到峰值速度时松线（而不是划水结束），附加质量项从 −10 变到 ≈0。
3. 髋摆幅 60°→90° 使压差推力翻倍以上（桨速 ∝ 摆幅，推力 ∝ 桨速²）。
4. 划水占比 0.5→0.3（划得快、收得慢）：压差推力 7 → 12 mN。
5. 蜷缩角 φ_ret、收拢宽度、展开角都是次级参数（各 1–3 mN）；蜷缩到 40–60° 已足够，再收更多没有收益、还会在伸展/收拢瞬间产生力尖峰。
6. 周期变短压差推力大增，但附加质量惩罚随加速度² 增大——只有配合早松线才划算。
7. 改进步态在 U = 0.1 m/s 下单腿 +12.9 mN → 四腿约 50 mN，远大于光船体在该速度的阻力估算（~5 mN）：这套步态应能推到 0.15 m/s 以上；基准步态维持不了 0.1 m/s。

伸展/收拢的一个几何特点：φ≈90° 附近平行四边形的伸缩方向与桨轴平行（桨"沿自身方向滑动"，几乎无阻力）；φ 越小，伸缩越接近迎面推水。
所以蜷缩/伸展动作尽量在 φ 60–120° 区间完成、避免在 φ<40° 快速动作。

用法：
    python3 leg_dynamics.py                                                            # 基准
    DUTY=0.3 FAN_CLOSE=0.15 CLOSED_W=0.012 FAN_DEG=150 SWEEP=90 PHI_RET=60 python3 leg_dynamics.py   # 改进
拿到真实舵机曲线后替换 gait()（返回 ψ(t)、φ(t)）即可；paddle_open.stl / paddle_closed.stl 为 CFD 两态脚蹼几何。
