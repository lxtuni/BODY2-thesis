# V3 步态的运动方程（与 `V3_leg_anim.mp4` 对应）

视频：`V3_leg_anim.mp4`（`leg_dynamics.py` 动画，参数 `T=0.81 DUTY=0.45 SWEEP=50 PSI_START=120 SWITCH_FRAC=0.5 CLOSED_W=0.012`，一个周期放慢到 5 s；箭头是准定常示意力，不是 CFD）。
坐标：机体坐标，x 前、z 上，O2（下舵机轴）= (63.4, 4.0) mm，水线 z = −10 mm。角度从 +x 逆时针为正。

## 1 参数

| 符号 | 值 | 含义 |
|---|---|---|
| T | 0.81 s（1.23 Hz） | 周期 |
| DUTY | 0.45 | 划水相占比（划水 365 ms，回收 445 ms） |
| ψ0, SWEEP | 120°, 50° | 摇臂 O2→C 的起点角与摆幅：120° → 70°，中点 95°（≈ 竖直） |
| φ_ext, φ_ret | 105°, 40° | 平行四边形张角 φ = θ2 − ψ：划水伸展 / 回收蜷缩 |
| SWITCH_FRAC | 0.5 | 回收相前一半收、后一半放（慢蜷缩） |
| 扇 | 120°，R 42 mm | 张开 20 cm²，尾宽 73 mm；收拢 12 mm |
| t_r | 0.08 T = 65 ms | 开/合过渡 |

## 2 关节空间（这就是 V3 的定义）

τ = (t / T) mod 1

相位角：ph(τ) = π·τ/DUTY（τ < DUTY，划水）；ph(τ) = π + π·(τ − DUTY)/(1 − DUTY)（回收）

**摇臂角** ψ(τ) = ψ0 − SWEEP/2 + (SWEEP/2)·cos ph(τ) = **95° + 25°·cos ph(τ)**
- 划水相 ψ: 120° → 70°（向后扫），回收相 70° → 120°
- 角速度 ψ̇ = −25°·sin(ph)·dph/dt：划水峰值 25°·π/(DUTY·T) = **215 °/s**（τ = 0.225），回收峰值 176 °/s（τ = 0.725）——余弦律，起止为零

**平行四边形张角** φ(τ)：
- 划水相：φ = 105°
- 回收相：rec = (τ − DUTY)/(1 − DUTY)；b = rec/0.5（rec < 0.5），b = (1 − rec)/0.5（rec ≥ 0.5）；b̃ = ½ − ½·cos(π·b)；**φ = 105° − 65°·b̃**（τ = 0.725 时最蜷 40°，τ = 1 回到 105°）

**舵机指令**：servo_1（曲柄 2 绝对角）θ2 = ψ + φ，范围 133°…225°；servo_2（曲柄 1）θ1 由四杆闭环 `crank1_from_rocker(ψ + π)` 数值求解，范围 −100°…−52°。

**脚蹼开度** f(τ)：f = τ/0.08（τ < 0.08）；1（0.08 ≤ τ < 0.45）；1 − (τ − 0.45)/0.08（0.45 ≤ τ < 0.53）；0（其余）。桨头宽 w = 73·f + 12·(1 − f) mm。

## 3 各点位置（mm，机体坐标）

rot(a) = (cos a, sin a)
- C = O2 + 14.7·rot(ψ)（摇臂短端 = 平行四边形地杆）
- D = O2 + 39·rot(ψ + φ)（曲柄 2）
- E = C + (D − O2)（桨根，平行四边形闭合）
- B = O2 + 30.1·rot(ψ + 180°)（摇臂长端，接连杆）
- 桨轴 u = rot(ψ + 180°)（从 E 指向桨尖，与摇臂平行）；桨面法向 n = (−u_z, u_x)
- 桨头中心 P = E + 71·u；桨尖 = E + 92·u（细杆 50 + 桨头 42）

一个周期桨尖轨迹范围：x ∈ [−2, 74] mm，z ∈ [−91, −45] mm；桨尖最大速度 0.38 m/s。

## 4 时间表（ms，从划水开始计）

| t | τ | 事件 |
|---|---|---|
| 0 | 0 | 划水开始，ψ = 120°，开扇开始 |
| 65 | 0.08 | 全开 |
| 182 | 0.225 | ψ = 95°（竖直），ψ̇ 峰值 215 °/s，推力峰 |
| 365 | 0.45 | 划水结束 ψ = 70°，松线收扇开始，φ 开始蜷缩 |
| 430 | 0.53 | 全闭 |
| 587 | 0.725 | 回收中点 ψ = 95°，φ = 40°（最蜷）；之后伸展 |
| 810 | 1.0 | 回到 ψ = 120°，φ = 105° |

## 5 固件用的足端方程（`gait_to_firmware.py`，原点 O2，+x 前 +y 上）

固件几何：O2E = 60、EM = 35、O2B = 25（mm）。q2 = 摇臂角（`direct`：q2 = ψ；`mirror`：q2 = 180° − ψ，O1 前/后的镜像问题仍待你确认），γ = q2 + φ'，φ' = −φ（伸展 −105°，蜷缩 −40°）：

**M(τ) = (60·cos γ − 35·cos q2,  60·sin γ − 35·sin q2)**

把 §2 的 ψ(τ)、φ(τ) 代入即可；20 个控制点的 C 数组和逐 ms 的 CSV 在 `results_verify/firmware/V3_direct_*` 与 `V3_mirror_*`。

## 6 V3+（零成本改进，来自 `results/papers/fold_timing_sweep.py`）

只改开合时刻、不改 ψ/φ：**收扇提前到 τ = 0.36（292 ms）**，**开扇指令提前到上一周期 τ = 0.95（770 ms）**。两态合成估计周期平均推力 49.3 → ≈ 53 mN（+8 %）。这要求松线时刻可控，不能是"划水结束自动松"。
