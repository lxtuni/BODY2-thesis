# BODY2 平滑船体 M3（整船，可直接打印）— 使用说明

生成日期 2026‑09‑14。目标：把原 `密封身体0826.STEP` 的水下部分换成**全光滑（连续曲率，无折角）**的新型线 M3，水线以上保留原上部（腿槽 Beinschlitze、法兰 Flansch、8 个沉头孔 Senkbohrungen、2 mm 壁）；总尺寸、排水量、浮心均与原船一致，可直接 3D 打印做实验。

## 2 坐标与尺寸（零件坐标系 = 0826.STEP，单位 mm）

- x 沿船长（尖端 Spitz −x、钝端 Stumpf +x），y 向上，z 横向。与 CFD 坐标的关系：x_CFD = −x，z_CFD = y，y_CFD = z。
- 对接面 / 设计水线 WL：y = −10（原船的"密封面"高度）；顶缘 y = +15；新龙骨最深点 y = −48.43（x = 17.2）。
- 总包络 262 × 116 × 63.4（长 × 宽 × 高，高 = 从龙骨到顶缘；原船 50）；顶缘 262 × 116 不变。
- 水线以下：LWL 233.4，BWL 98.8，吃水 Tiefgang 38.4，排水量 **385.1 cm³**（= 原船，因此同样的机器人总质量下水线高度不变），浮心 LCB x = 11.34（= 原船，纵倾不变），水线面积 182 cm²，方形系数 Cb 0.435。
- 材料体积 88.6 cm³ → **PLA ≈ 110 g，PETG ≈ 113 g**（原船 91.4 cm³，基本相同）。
- 壁厚：水下壳 2.0 mm（三维法向等厚，实测中位 1.98，最小 1.84）；原上部 2 mm 不变。

## 3 型线定义（全部解析、可复现）

- 水线轮廓 b_w(x)：直接取 0826 外表面（B 样条面）在 y = −10 的截面 —— 本身光滑，也保证与上部严丝合缝。
- 龙骨线 D(x) = T3·(1−ξ)^0.8·(1+ξ)^0.85·(1+aξ)，ξ = (x−x_c)/L_h；T3 = 37.64 mm、a = 0.217 由「排水量 = 385.1 cm³」和「LCB = 11.34」两个条件解出。指数 0.8 / 0.85 使首尾龙骨线到达水线时的倾角与上部首尾轮廓相接（侧视无折角）。
- 横剖面 b(t) = b_w·(1−k·t)·√(1−t²)，t = 深度分数（0 水线，1 龙骨）；k = s·D/b_w（s = 上部在水线处的外飘斜率）→ 水线处斜率与上部**C¹ 连续**，横剖无折角。
- 首尾都收成一点（loft 顶点），龙骨处曲率半径最小 ≈ 10 mm（首尾），中部 ≈ 30 mm；每 1 mm 弧长转角中位 2.1°。
- 旧 M3 图上的折角来自 STL 切片，不是 CAD；这次的 STEP 是精确 B‑rep 曲面。

## 4 SolidWorks 里怎么用（2026 SP3.2 可直接打开）

1. 文件 → 打开 `BODY2_M3_hull_print.step`（16 MB，导入约 1 min；导入选项里勾"实体"、不用勾"曲面"）。得到一个含 2 个实体的零件。
2. 插入 → 特征 → **组合 Combine**（添加），选两个实体 → 单体。搭接环与原壁重叠 1.5 mm，所以布尔稳定；若报错，先用 工具 → 检查 修复，再组合。
3. 之后照常修改（加配重舱、螺纹孔、密封槽…），另存 STL 时用"精细"或自定义：偏差 0.01 mm、角度 5°。
4. 只想改水下形状：打开 `BODY2_M3_underwater_envelope.step`，用 抽壳 Shell 2 mm（顶面开口）即可得到水下壳。

## 5 3D 打印建议

- 尺寸 262 × 116 × 63：需要 ≥ 270 × 120 的平台（Ultimaker S5 / Prusa XL / Bambu H2D / K1 Max 可整体打印；Prusa MK4 250×210、Bambu X1 256×256 **放不下**，需在 SolidWorks 用 分割 Split 在 x = 0 附近切成两段，做 3–5 mm 搭接台阶后胶接 + 环氧密封）。
- 摆放：**顶缘朝下（船底朝上）**。这样水下曲面全部朝上无悬垂；上部外飘一般 ≤ 36°，不需支撑（只有尖端水线附近几 mm 高的局部 ≈ 50°，会略有下垂，可不管或局部加支撑）；4 个腿槽的悬空底面需要少量支撑（从顶缘一侧拆，容易）。内腔顶部（龙骨内侧）约 ±30 mm 区域是缓变穹顶，一般能自桥接，只影响内表面外观；追求内表面质量可加"仅内腔"树状支撑。
- 参数：0.2 mm 层高，0.4 喷嘴 **4–5 条周长（把 2 mm 壁打成实心）**，顶/底 5 层，无需填充；PETG 更耐水（PLA 也可，短时实验够用）。防水：打印后内表面刷 2 遍清漆或环氧；水线附近尤其要封。
- 质量预算：壳 110 g，排水量 385 g → 机器人整机（含电池、舵机、腿）应 ≈ 385 g 时水线正好在 y = −10；更轻则水线下降（吃水变浅）。

## 6 重新生成（改参数）

```
cd scripts
python3 hull_design.py                       # 只算型线参数（需 orig_outlines.json）
python3 draw_lines.py                        # 三视线图
python3 make_hull_M3_full.py --out .. [--wall 2.0] [--loft-tol 2e-3]   # 放样 + 内腔 + 原上部 → STEP/BREP（约 3–4 min）
python3 make_print_stl.py                    # 两体网格并集 → 单壳封闭 STL（读 ../_upper.brep、../_shell_lower_ring.brep）
python3 check_stl.py                         # 封闭性 / 壁厚 / 接缝 / 曲率检查图
python3 render_stl.py                        # 渲染图
```
前提：把 `密封身体0826.STEP` 复制到 scripts/ 并改名 `body0826.step`（或加 `--step 路径`）；输出目录用 `--out ..` 指到本文件夹。改吃水或型线：`hull_design.py` 里 `P_B, P_P, KMAX`，以及 `V_TARGET, LCB_TARGET`（默认 = 原船）。改壁厚：`--wall`。环境：Python 3.11 + cadquery 2.8（OCP）、trimesh、manifold3d、scipy、matplotlib。

## 7 已做的检查

- 水下外形实体 valid，385.1 cm³；水下壳（含搭接环）valid 单体 49.6 cm³；原上部 41.0 cm³。
- 打印 STL：1 个连通壳、watertight、法向一致、体积 88.53 cm³。
- 壁厚（内表面点到外表面距离）min 1.84 / 中位 1.98 / max 2.9 mm（> 2 的是首尾内腔收尖处）。
- 接缝 y = −10：下壳 (y = −10.3) 与上壳 (y = −9.7) 轮廓的法向距离中位 0.23 mm、最大 0.68 mm（首尾外飘），即 0.6 mm 高差上的正常外飘，无台阶。
- 曲率：横剖面每 1 mm 弧长转角最大 5.6°（首尾龙骨），中位 2.1°；侧视首尾龙骨与上部轮廓相接。
